## Sobre o Projeto

**OncoPed-360** é um recorte dedicado à **oncologia infanto-juvenil no Brasil**, construído em cima do dataset [Onco-360](https://github.com/rafa-trindade/onco-360-foundation), que reúne rede assistencial, mortalidade, repasses públicos, procedimentos e diagnóstico de câncer no país.

Em vez de um pipeline de extração próprio, este projeto consome diretamente as bases já publicadas e padronizadas do Onco-360, aplicando os recortes pediátricos já sinalizados nelas (habilitações pediátricas do CNES, faixas etárias da PNS, incidência infanto-juvenil do INCA) para produzir análises e, futuramente, um painel público e interativo sobre o tema.

> 🚧 **Projeto em desenvolvimento.** Estrutura, escopo e entregas ainda estão sendo definidos.
